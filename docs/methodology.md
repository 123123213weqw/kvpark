# Measurement rules

1. Test actual hardware; record CUDA, PyTorch, driver, PCIe state, and GPU model.
2. Do not label RTX GDDR memory as HBM or SATA/HDD storage as NVMe.
3. Use real, randomly generated bytes, not sparse files, repeated zeros, or unmaterialized allocations.
4. Separate direct backing-device reads, uncontrolled buffered reads, pinned-RAM hits, and copy-only baselines.
5. Do not use global `drop_caches` on a shared machine. Explicit Linux O_DIRECT payload reads avoid
   filesystem cache contamination without altering other workloads. Controller cache remains possible.
6. Warm CUDA initialization and transport buffers before repeated timed measurements.
7. Time until CUDA work actually completes. A nonblocking call's enqueue time is not transfer latency.
8. Keep per-run samples; show medians and observed tails, not a selectively chosen best run.
9. Record checksum settings. An unchecked transport path and a validated path are different experiments.
10. Validate byte equality after disk and RAM paths. Separately compare model logits and continuation.
11. Report prefetch and durable write time separately. A RAM hit achieved after a 6-second prefetch
    is not a 6-second cold-restore elimination unless scheduling actually supplied that look-ahead.
12. Account for retained pinned memory, staging, GPU source/output tensors, and allocator high-water.
13. Disclose shared GPU use. These experiments do not kill existing services for cleaner numbers.
14. Compare prefix restore with prefix recompute on the same model, dtype, prompt length, device,
    and attention backend. Synthetic bytes cannot prove production TTFT or tokens/s improvements.
15. A tiny randomly initialized model proves execution correctness, not model quality or production benefit.
16. Cost arithmetic must identify supplied prices and exclusions. Installed capacity has zero incremental
    purchase cost, not zero power, wear, redundancy, maintenance, or opportunity cost.
17. In a known-queue experiment, report both service-only TTFT and arrival/queue-inclusive TTFT.
    All queued requests arrive at each mode's measured start; initial prefetch and subsequent waiting
    therefore count toward arrival latency. Also report total wall time, not only the best fast path.

Transport GB/s uses decimal gigabytes; MiB/GiB capacities use binary units. Published JSON intentionally
omits hostnames, addresses, usernames, private prompts, token IDs, and model-cache contents.
